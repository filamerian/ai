BSIT Syntax & Concept Codex

Quick reference guide for programming fundamentals, syntax structures, and best practices.

Variables & Data Types

Containers for storing data values. Common types include Integer, Float, String, and Boolean.

let age = 20; // Number
let studentName = "Alex"; // String
let isEnrolled = true; // Boolean
Control Structures (If/Else)

Execute different code blocks based on conditional Boolean statements.

if (grade >= 75) {
    return "Passed";
} else {
    return "Remedial";
}
Loops & Iteration

Repeat a block of code multiple times while a specific condition holds true.

for (let i = 0; i < 5; i++) {
    console.log("Iteration: " + i);
}
Arrays & Collections

Ordered lists of elements accessible via zero-based index numbers.

let servers = ["Web", "Database", "DNS"];
console.log(servers[0]); // Output: "Web"
servers.push("API"); // Add item
Functions & Parameters

Reusable blocks of code designed to perform a specific computational task.

function calculateTotal(price, tax) {
    return price + (price * tax);
}
